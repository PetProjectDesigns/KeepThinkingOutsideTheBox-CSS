CSS Float and Clear Demonstration

float: left
Floating Left
This text wraps around the box that is floated to the left. Floats allow elements to move to the left side of their container while other content flows around them.
This element uses clear: both to move below the float.
float: right
Floating Right
This text wraps around the box that is floated to the right. Floats are often used for images or small layout elements that should sit to one side.
This element clears the float and appears below it.
