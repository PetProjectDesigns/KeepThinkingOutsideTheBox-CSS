How to Use a Custom Font with @font-face

Let's start with the tempated example: 

@font-face {
  font-family: "MyCustomFont";
  src: url("font.woff2") format("woff2"),
       url("font.woff") format("woff");
}

body {
  font-family: "MyCustomFont", sans-serif;
}

To use a custom font with @font-face, you only need to update a few parts of the code:

1. Change the font-family name

This is your internal nickname for the font. It doesn’t need to match the real font’s name. Example: font-family: "CoolTitleFont";

2. Change the file names to match your actual font files

If your font files are named MyFont-Regular.woff2 and MyFont-Regular.woff, your src should match exactly: 

@font-face {
  font-family: "CoolTitleFont";
  src: url("MyFont-Regular.woff2") format("woff2"),
       url("MyFont-Regular.woff") format("woff");
}

3. Make sure the file paths are correct

If your fonts are inside a fonts/ folder, update the paths: 

src: url("fonts/MyFont-Regular.woff2") format("woff2"),
     url("fonts/MyFont-Regular.woff") format("woff");

Putting It All Together

@font-face {
  font-family: "FriendlySans";
  src: url("FriendlySans-Regular.woff2") format("woff2"),
       url("FriendlySans-Regular.woff") format("woff");
}

body {
  font-family: "FriendlySans", sans-serif;
}

Now your webpage will use FriendlySans everywhere. Think of it like labeling a jar:

  • font-family = the label you put on the jar
  • src = the actual font files inside the jar
  • CSS usage = “Hey browser, use the stuff in the jar called FriendlySans”
